# Macros screen files (prebuilt)

These are the DGUS-reloaded-Klipper 1.0.2 screen files with the Macros page
added. They're generated by `dgus_lcd/macros_screen.py`, so don't edit them
by hand. Flash them with:

    ~/dgus-env/bin/python -m dgus_lcd.dgustool upload screen/macros

See ../../docs/MACROS.md. Based on Desuuuu's DGUS-reloaded-Klipper (GPLv3).
